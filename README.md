# YouTube Downloader

Приложение для Windows с графическим интерфейсом на CustomTkinter для скачивания видео с YouTube. Интерфейс — на украинском языке.

## Возможности

- Получение названия, длительности и доступных разрешений видео по ссылке.
- Выбор качества и папки сохранения.
- Отображение прогресса, скорости и оставшегося времени.
- Сохранение в MP4 с объединением видео и звука через FFmpeg.
- Показ ошибок загрузки; успех подтверждается после обработки и проверки готового непустого файла.

Выбранное разрешение задаёт верхнюю границу качества: загрузчик выбирает лучший доступный вариант, не превышающий её. Ссылка на видео с параметром плейлиста скачивает только выбранное видео.

## Запуск готовой сборки

Откройте файл:

```text
builded\YouTubeDownloader\YouTubeDownloader.exe
```

Вставьте ссылку на видео, дождитесь списка качеств, выберите разрешение и папку, затем нажмите «Завантажити відео».

Для переноса приложения копируйте **всю папку `YouTubeDownloader`**, включая `_internal`. Отдельно перенесённый `.exe` работать не будет. Python, Node.js и FFmpeg отдельно устанавливать для готовой сборки не требуется: необходимые компоненты включены в неё.

Сборка использует режим PyInstaller `--onedir`: зависимости хранятся рядом с программой, что позволяет избежать их распаковки при каждом запуске. Готовые сборки исключены из Git; после клонирования репозитория их нужно создать самостоятельно.

## Запуск из исходников

Для разработки и сборки нужны:

- Windows и Python с Tkinter и pip. Проект проверен на Python 3.14.
- Node.js 22 или новее в `PATH` для обработки JavaScript YouTube.
- `ffmpeg.exe` и `ffprobe.exe` в `PATH` для обработки видео и звука.

В PowerShell перейдите в папку проекта и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Запускайте `app.py` из папки проекта, чтобы приложение нашло `icon.ico`. Зависимости `yt-dlp[default]` включают EJS-компоненты для работы с YouTube.

## Сборка приложения

Закройте запущенное приложение и выполните:

```powershell
.\build.bat
```

Скрипт проверяет инструменты, создаёт или использует `.venv`, устанавливает зависимости из `requirements.txt` и собирает приложение вместе с Node.js, FFmpeg, FFprobe и EJS.

Результат:

```text
builded/
└── YouTubeDownloader/
    ├── YouTubeDownloader.exe
    └── _internal/
```

При успешной пересборке скрипт удаляет предыдущую папку `builded` и заменяет её новой. Не храните в ней скачанные видео или другие личные файлы.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s . -p test_downloader.py -v
```

Тесты проверяют, что ошибки, ненулевой код результата, отсутствие готового файла и пустой файл не вызывают сообщение об успехе. Они выполняются без обращения к YouTube.

## Решение проблем

- **Ошибка HTTP 403 или ошибка извлечения данных:** проверьте актуальность `yt-dlp`, совместимость EJS и наличие Node.js. После изменения версии в `requirements.txt` переустановите зависимости и пересоберите приложение. Доступность конкретного видео также зависит от ограничений YouTube.
- **Не найден Node.js, FFmpeg или FFprobe при сборке:** добавьте папки с исполняемыми файлами в `PATH` и откройте новый терминал.
- **Не получается заменить сборку:** закройте запущенный `YouTubeDownloader.exe` перед повторным запуском `build.bat`.
- **Приложение не запускается после переноса:** убедитесь, что рядом с `.exe` находится вся папка `_internal`.

## Структура исходников

| Файл | Назначение |
| --- | --- |
| `app.py` | Точка входа |
| `gui.py` | Интерфейс, выбор качества и отображение состояния |
| `downloader.py` | Работа с yt-dlp, поиск инструментов и проверка результата |
| `build.bat` | Сборка приложения для Windows |
| `requirements.txt` | Зависимости Python |
| `test_downloader.py` | Регрессионные тесты обработки результата загрузки |
